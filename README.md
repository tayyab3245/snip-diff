## What SNIP-DIFF Does

SNIP-DIFF is a desktop application that revolutionizes how developers work with AI language models by providing intelligent code diffing, context optimization, and snippet generation tools.

### Smart Code Diffing
Automatically detect and analyze Git repository changes. Compare different versions of files with syntax highlighting. Identify additions, deletions, and modifications with precision. Real-time diff processing as you work.

### AI Context Optimization
Calculate LLM context usage for different AI providers. AI-powered change summaries using Google Gemini. Optimize code snippets for model context limits. Tailored output for GPT, Claude, Gemini, and more.

### Snippet Management
Copy formatted code snippets to clipboard. Beautiful code presentation with language detection. Browse and select files from your project structure. Pre-configured formats for different AI workflows.

### Modern Desktop Experience
Works on Windows, macOS, and Linux. Sophisticated UI with smooth animations. Eye-friendly interface optimized for long coding sessions. Adapts to different screen sizes and workflows.

## Use Cases

### For AI-Assisted Development
Generate concise summaries of code changes for AI review. Create focused code snippets for debugging with AI. Share specific code sections with AI for refactoring suggestions. Generate code examples with proper context.

### For Technical Communication
Share precise code diffs with colleagues. Create focused diff snippets for PR discussions. Export code examples with syntax highlighting.

### For LLM Context Management
Ensure your code fits within model context limits. Format snippets for different AI model requirements. Maintain code relationships and dependencies.

## Key Features

### File Operations
Browse local file systems and Git repositories. Real-time file watching and change detection. Syntax highlighting for programming languages. Directory tree navigation with search and filtering.

### Diff Processing
Git diff analysis and visualization. Side-by-side and unified diff views. Change highlighting and line-by-line comparison. Live diff updates during development.

### AI Integration
Google Gemini AI for intelligent summarization. Token counting for major LLM providers. Context-aware snippet generation. Export formats optimized for AI consumption.

### User Experience
Native desktop application. Keyboard shortcuts and accessibility features. Dark theme optimized for coding. Responsive design for different workflows.
